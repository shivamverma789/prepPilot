SECTION 2: ABSTRACT (approx 500 words)
================================================================

PrepPilot is a full-stack, AI-powered web application designed to assist
engineering students in preparing for campus placements and technical job
interviews. The platform addresses a critical gap in the current placement
preparation ecosystem — the absence of a unified, personalized, and
intelligent system that adapts to each student's unique academic background,
skill level, and career goals.

The system is built using Node.js with the Express 5 framework on the
backend, MongoDB as the primary database via Mongoose, and EJS as the
server-side templating engine for rendering views. All AI features are
powered by Google Gemini (gemini-3-flash-preview model) accessed through
a centralized AI client service that supports key rotation and retry logic.

PrepPilot offers six core modules:

1. AI Personalized Roadmap Generator: Based on a student's onboarding
profile (skills, career goals, academic year, target company type), the
system generates a phase-wise, week-by-week learning roadmap with
subtopics, resources (YouTube + documentation), and mini projects.

2. ATS Resume Analyzer: Students upload their resume (PDF or DOCX), which
is parsed and analyzed by the AI to produce an ATS score, keyword gaps,
critical issues, improvement suggestions, and rewrite examples. A
job-description-based analysis mode is also available.

3. Resume Builder: A structured, section-based resume editor allowing
students to build resumes from scratch with sections for basics, summary,
skills, experience, projects, and education. AI enhancement rewrites
bullet points for impact. PDF export is supported via Puppeteer.

4. Skill Assessments: AI-generated 5-question MCQ quizzes for each
subtopic in the student's roadmap, with difficulty progression and
detailed explanations.

5. DSA Activity Tracker: Aggregates coding activity from LeetCode,
Codeforces, CodeChef, HackerRank, and GitHub using their respective APIs,
displaying streaks, ratings, and activity heatmaps.

6. AI Mock Interview Setup: Configures and launches AI-driven mock
interview sessions integrated with a LiveKit-based real-time interview
application.

The platform uses Passport.js for authentication (local strategy + Google
OAuth + GitHub OAuth), session management via connect-mongo, and bcrypt
for password hashing. Email verification is handled through Brevo (formerly
Sendinblue) SMTP.

PrepPilot is deployed on Render (cloud platform) with MongoDB Atlas as the
cloud database. The application is live at https://preppilot.in.

Keywords: Placement Preparation, Artificial Intelligence, ATS Resume
Analysis, Personalized Roadmap, Skill Assessment, Node.js, Google Gemini,
MongoDB, Express.js, Full Stack Web Application

1.1 INTRODUCTION

The placement season in Indian engineering colleges is one of the most
critical phases of a student's academic journey. Despite the availability
of numerous online resources, students often struggle with three core
problems: (a) not knowing what to study, (b) not knowing how to present
their skills, and (c) not getting enough practice in a realistic setting.

PrepPilot was conceived to solve all three problems in a single, unified
platform. It acts as a personal placement coach — understanding the
student's current skill level, generating a customized learning path,
helping them build and optimize their resume, and providing tools to
practice and track their progress.

The platform is entirely web-based, requiring no installation, and is
accessible from any device with a browser. It is free to use and designed
specifically for the Indian engineering student demographic targeting
product-based companies, service-based companies, startups, and FAANG-level
organizations.

3.1 ALGORITHM (AI PROMPT ENGINEERING)

The core intelligence of PrepPilot is driven by carefully engineered
prompts sent to the Google Gemini API. The prompt engineering follows
a structured approach:

Roadmap Generation Algorithm:
1. Collect user profile (skills with levels, goals, academic year,
   target company, experience)
2. Build a structured user profile text block
3. Send to Gemini with strict JSON output schema
4. Parse response and store phases/skills/subtopics in MongoDB
5. Render roadmap on dashboard

Resume Analysis Algorithm:
1. Accept uploaded file (PDF/DOCX)
2. Extract raw text using pdf-parse or mammoth
3. Send text to Gemini with scoring framework prompt
4. Parse JSON response (ATS score, breakdown, issues, suggestions)
5. Render results page with visual score breakdown

Quiz Generation Algorithm:
1. Receive subtopic title, skill title, user level
2. Send to Gemini requesting 5 MCQ questions in JSON format
3. Parse and validate response
4. Render quiz UI with options and submit handler
5. Score answers and display explanations

3.2 SYSTEM ARCHITECTURE

PrepPilot follows the MVC (Model-View-Controller) architectural pattern:

Model Layer (MongoDB + Mongoose):
- userModel.js — User accounts, profile, skills, goals, academic info

5.2 BRIEF DESCRIPTION OF VARIOUS MODULES

Module 1 — Authentication & Onboarding:
Handles user registration, email verification, login (local + OAuth),
and the 4-step profile setup. Uses Passport.js strategies and
connect-mongo for persistent sessions.

Module 2 — AI Roadmap Generator:
Takes the user's complete profile and sends a structured prompt to
Google Gemini. The response is a JSON array of phases, each containing
skills with subtopics, resources, and mini projects. Stored in MongoDB
and rendered as an interactive roadmap on the dashboard.

Module 3 — Resume Analyzer:
Accepts PDF/DOCX uploads via Multer (memory storage). Text is extracted
using pdf-parse or mammoth. The text is sent to Gemini with a detailed
scoring framework prompt. Results include ATS score (0-100), section
breakdown, critical issues, missing keywords, and rewrite examples.

Module 4 — Resume Builder:
A full CRUD resume editor with 6 section types (text, grouped-list,
entries). Supports adding/editing/deleting entries and bullet points.
AI enhancement sends the resume to Gemini for optimization. PDF export
uses Puppeteer to render an EJS template and generate a PDF buffer.

Module 5 — Skill Assessment:
For each subtopic in the roadmap, the system generates a 5-question MCQ
quiz using Gemini. Questions have 4 options, difficulty levels (basic/
intermediate/advanced), and explanations. Results are scored and displayed
immediately.

Module 6 — Activity Tracker:
Uses axios to call public APIs of LeetCode (GraphQL), Codeforces (REST),
CodeChef, HackerRank, and GitHub. Aggregates problem counts, ratings,
streaks, and contribution data into a unified dashboard view.

Module 7 — Mock Interview:
Collects interview configuration (role, difficulty, focus areas) and
redirects to the LiveKit-based AI interviewer application with parameters
passed as query strings.
